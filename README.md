# 泄密倒计时：最后一次授权

一款围绕半导体信息安全设计的真人式图文互动 H5。玩家扮演产品工程师林澈，在星桥 S7 项目交付日处理测试异常、AI 摘要、团队合照、合作方需求和最终邮件授权，并通过证据回放看到信息如何跨越边界。

## 当前体验

- 约 18～25 分钟、16 个连续场景，从 17：52 的危险附件倒叙回到 09：08。
- 林澈、顾言、小满、程默和许航五名写实角色立绘，以及 AI 助手小芯。
- 全屏电影场景、底部人物对话和场景内任务交互，不使用固定的左右选择栏。
- 调查线索、事实分类、AI 资料选择、来源核对、拍照取景、照片遮挡、发布文案、通话澄清、自由核对、AI 计划和证据连线等互动。
- 时间成本只由重拍或澄清等行动产生；阅读剧情不消耗时间。
- 读取、生成草稿和模拟发送分别记录，结局统一来自 `src/domain/evaluate.ts`。
- 浏览器本地保存进度；无需登录、后端、数据库或实时 AI。

公开演示地址：<https://zk1234-q.github.io/semiconductor-security-h5/>

## 直接打开演示

双击 `dist/index.html` 即可离线体验，无需安装依赖或启动服务器。也可双击根目录 `index.html`，它会自动进入离线构建入口。

构建结果把脚本、样式和游戏图片内嵌在单个 HTML 文件中，可单独复制用于演示。浏览器允许本地存储时会保存进度；禁用本地存储时仍可完成体验。

## 开发调试

```bash
npm install
npm run dev
```

构建交付版本：

```bash
npm run check
npm run build
```

离线回归测试需要本机 Chrome；其他安装位置可通过 `CHROME_PATH` 指定：

```bash
npm run test:offline
```

测试覆盖根目录离线入口、16 场景安全路线、16 场景风险路线、演示入口、移动端横向溢出、本地存储不可用和浏览器脚本异常。截图保存在 `.tmp/offline-entry/`。
