# 项目架构

## 产品形态

单页互动 H5，以全屏场景、角色立绘、底部对话和场景内任务推动剧情。首版为本地纯前端应用，不连接后端、数据库或实时 AI。

## 数据流

```text
剧情状态 story + 操作草稿 drafts
  → 玩家确认
  → 写入已确认记录 records
  → src/domain/evaluate.ts 统一计算
  → 证据回放与结局读取同一结果
```

`src/domain/evaluate.ts` 是结果判断的唯一来源。`src/ui/game-render.ts` 只负责呈现，`src/main.ts` 负责事件和场景导航，`src/app/state.ts` 负责初始化与本地持久化。

## 场景流

```text
封面 → 傍晚悬念 → 上午异常调查 → 事实分类 → AI 摘要 → 来源核对
     → 合照取景 → 照片检查 → 文案选择 → 合作方通话 → 两项自由核对
     → AI 执行计划 → 线索连线 → 最终邮件 → 证据回放 → 结局
```

## 状态边界

- `story`：对话步数、额外时间、调查发现和尚未形成执行记录的剧情选择。
- `drafts`：报告、照片和授权三个任务当前尚未确认的操作。
- `records`：玩家已确认的资料处理、照片发布和邮件执行事件。
- `replay`：保留兼容字段，当前 16 场景版本不修改原始记录。

## 渲染结构

- `src/ui/game-render.ts`：新版本全屏游戏渲染器。
- `src/styles-game.css`：场景、对话、任务面板、照片热点和响应式布局。
- `src/ui/render.ts` 与旧样式文件：保留旧版本参考，不再由入口加载。

## 媒体接入

网页尺寸角色素材保存在 `src/assets/game/`，由 Vite 内嵌进离线 HTML。精确文字、批次号、按钮和照片热点由页面渲染，图片只承担人物和环境演出，避免依赖生成图中的文字。
