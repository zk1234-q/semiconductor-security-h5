# 视觉规范

## 核心视觉

- 背景使用深蓝近黑 `#050a12`，主强调色使用青色 `#62e6ff`，注意色使用琥珀色 `#ffca73`，风险色使用红色 `#ff746f`。
- 桌面端采用全屏电影场景：时间与地点位于左上角，工作记录位于右上角，人物对话位于底部，互动任务进入画面主体。
- 不使用固定的左图右选项布局，不使用没有实际功能的顶部进度条。
- 半透明面板只用于道具、文件、照片检查和执行计划，背景保持人物与环境可见。

## 对话与任务

- 对话框显示人物立绘、姓名、岗位和一句台词。
- 最后一段对话以“开始行动”结束，任务出现时对话框收起，避免遮挡可操作区域。
- 当前任务通过标题、简短目标和明显的主按钮表达；可操作物使用光标、描边和即时状态反馈。
- 风险颜色用于已经呈现的敏感区域或已确认结果，不在普通选择前标注标准答案。

## 人物与剧情图

- 角色采用统一的写实商业游戏人物风格、成年人比例和克制的电影光影。
- 林澈穿浅蓝衬衫，顾言穿藏蓝衬衫与细框眼镜，小满穿米白针织开衫与珊瑚色内搭，程默穿深灰工程衬衫，许航穿灰蓝商务外套。
- 上午异常场景使用专用剧情图；午间合照由固定角色立绘和可操作背景道具合成，确保人物连续性与热点稳定。
- 编号、文件名和测试信息由 HTML 叠加，避免生成图片中的伪文字。

## 响应式

- 820 px 以下改为单列任务和紧凑对话框，照片、通话、证据和结局依次纵向排列。
- 480 px 以下主按钮占满宽度，复杂控制改为单列。
- 手机端人物群像下沉为背景，正文和主要入口保持在首屏可操作区域。
- 页面不得出现横向溢出，支持 `prefers-reduced-motion`。
